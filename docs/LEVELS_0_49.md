# Prototype level pack set: 0–49

`levels/` contains 50 catalog-ready ZIP packages and matching previews. Level 0 keeps the earlier handcrafted 64x64 eight-template layout, including the pit-grid chunk. Levels 1–49 are procedural prototype packages with four 64x64 chunk templates each, an init Lua grid generator, original procedural placeholder textures, XML item-decomposition examples, and source metadata pointing to the corresponding `backroomswiki.ru/level-N` reference page.

No third-party 3D model or Poly Haven asset is bundled in these generated prototype packages. This avoids silently redistributing assets without the exact source/license/attribution record. Replace the placeholders only after adding an explicit attribution manifest for every imported external asset.

Monster declarations are intentionally conservative: the first iconic levels whose entity sections were reviewed during this revision get small representative rosters. Other packs do not invent monster rosters merely from a level title.
